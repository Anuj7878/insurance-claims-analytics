# Insurance Claims Analytics System

Large-scale insurance analytics and business intelligence project built using Python, Pandas, and synthetic data simulation.

## Features

- Generated 1M+ synthetic insurance policy records
- Simulated insurance claim events
- Calculated loss ratios and profitability
- Monthly claim trend analysis
- Future liability estimation
- Business intelligence reporting

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Data Analytics
- Business Intelligence

## Insights

- 240M+ premium analyzed
- 49K+ claims processed
- 36% portfolio loss ratio
- Future liability estimation included
